# 云岫归宁｜背景视频提示词

## 规范要求

请严格以随附的纯背景图作为构图、机位、色彩和画风依据，生成一段安静、细腻、可无缝循环的手机竖版背景视频。目标画幅为手机墙面区域 `1179×1840 px`，目标时长 `12 秒`、`24 fps`，无音轨。镜头完全锁定，不平移、不缩放、不摇晃，不改变透视、地平线、构图或曝光。保持天空渐层、日轮位置、山峰轮廓和远景结构稳定，只让「内容描述」指定的环境元素缓慢运动。首尾画面构图与光色相接，接缝前后运动连续；不闪黑、不跳位、不变形，不新增或删除物件。画面无文字、无 UI、无人像、无建筑前景、无祭台或供品；仅表现环境背景。

## 内容描述

延续纯背景图中的蓝灰群山、暖杏色晨光和细腻偏写实中式幻想绘画质感，表现开阔、宁静的山谷云海。远处云层几乎静止，中景云带沿山谷缓慢横向漂移，近处云团以稍快但柔和的速度舒卷；峰谷间的云雾产生轻微层次视差，形态自然连贯。云层在循环中缓慢回到首帧分布。日轮固定在原位，云面受光只作极轻微变化。整体安详、空灵、开阔，不做戏剧性风暴、快速翻涌或大幅光影变化。
