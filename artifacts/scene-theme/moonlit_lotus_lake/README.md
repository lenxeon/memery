# 月照莲湖场景

用户参考图拆分为湖景背景、树影灯笼近景、独立相框、石岸地面、供桌、黑金席垫和锦面蒲团。相框和地面是独立的全画布透明素材；原始带框图保留为设计参考。运行时素材及组合参数位于 `public/themes/moonlit_lotus_lake/`，通过 `public/themes/catalog.json` 注册。相框里的照片由软件动态绘制，供品由软件独立摆放；六组左右前景沿用现有候选，默认透明度为零。

`assembly-preview.png` 是依据配置参数生成的静态图层合成示意，不含动态照片、供品或运行时效果，不能替代软件内视觉检查。

用户提供的最初席垫经手工估计，远边/近边约 0.711、纵深投影/近边约 0.305，后者超出 0.17–0.21 标准。当前注册的修正席垫分别为约 0.711、0.188，符合比例范围；测量角点有约 ±5 像素不确定度，详细数据见 `audit/`。席垫和石板地面的共同消失点仍需在应用合成画面中复核。

供桌在 393×852 参考画布上，按当前配置估算桌面前沿约 329.5 px、投影纵深约 32.2 px。相框照片开口采用图片上的估计位置，仍需在软件中检查照片遮挡和圆框对齐。
