# 空间主题资产与镜头分层规范

## 1. 主题的定义

空间主题是一台完整镜头。它同时定义空间、深度、地面陈设、光源方向和色彩关系，不能只提供一张背景图。

供品、遗像内容和纪念文字仍是用户数据；主题只提供承托这些内容的视觉舞台。因此主题可以整体切换，用户摆放的花、果、香、烛不会丢失。

## 2. 移动端镜头与画面比例基准

所有主题共用正面居中的移动端镜头。整体渲染稿以 iPhone 16 竖屏 1179×2556 为手机基准（CSS 393×852）；iPad 竖屏以 2048×2732（CSS 1024×1366，3:4）为构图基准。墙纸和框架分别提供两种设备专属构图并铺满墙面，不拉伸手机图、不把手机图缩成平板中央窄幅，也不留空白墙带。墙区从画布顶端到 `y=0.72H`。设备专属的源图尺寸与铺放规则见 [主题 01 设备构图规范](scene-theme/device-layout-spec.md)。

| 构图要素 | 画面锚点 | 约束 |
| --- | --- | --- |
| 相机 | `x=0.50W`，正对墙面 | 无滚转；垂直线保持垂直；轻微俯视以看见桌面与地面；不使用夸张广角；地面单点透视消失区域靠近画面中轴的墙地交界。席垫和蒲团使用与整体渲染稿匹配的浅俯视角素材并作为精灵放置，不能二次做地面透视；墙灯正视、对称，需表现灯体结构和厚度 |
| 墙地交界 | 目标 `y=0.72H` | 可在 `0.70H–0.74H` 内微调；墙面占高约 70–74%，地面占高约 26–30%；各主题统一此比例锚点 |
| 遗像 | 中心 `x=0.50W, y=0.27H–0.34H` | 周围留出明确安静区；灯具、枝叶、造景附件不得穿过面容 |
| 纪念文案 | `y=0.37H–0.46H` | 按实际字数和字号预留空间；不被灯具、枝叶或供桌遮挡 |
| 供桌 | 中心 `x=0.50W`，宽 `0.84W–0.92W` | 主题 01 手机构图中台面约在 `y=0.72H–0.78H`；桌脚约在 `y=0.86H–0.88H` 并靠近席垫远边；完整露出台面、前沿和桌脚 |
| 席垫 | 桌脚前方，首版宽约 `0.62W` | 装饰物，不得藏在桌下；靠近桌前，尺寸需与整体渲染稿一致，不能缩得难以辨认，也不靠放大席垫填地面 |
| 蒲团 | 席垫上，首版宽约 `0.19W` | 独立装饰物，保持与地面匹配的浅俯机位；不能缩得难以辨认，也不能盖过供桌主体 |
| 蒲团/坐垫 | 独立叠在席垫上，宽 `0.12W–0.16W` | 装饰物；置于席面中部并留有边距，底边距画布底部不超过 `0.06H`；不可与席垫合成单张组件 |
| 前景 | 左右下方边缘 | 两侧独立；中心遗像、文案和供桌保持清晰；实体素材不带光斑 |

上述数值作为主题审核基准，不是必须机械填满的图层边界。各层可以因遮挡关系微调，但不得改变墙面为主体、地面为承托空间、供桌为视觉重点、席垫和蒲团为小型装饰的层级。Pixi 布局使用归一化比例或相对锚点，不写死设备物理像素。整体稿审核时标出画布尺寸、墙地交界、遗像中心、供桌台面/桌脚及地面饰物边界；用户审计通过前不批量扩充候选风格。

## 3. 墙体不是一张背景图

墙体按真实遮挡关系拆为五层：

| 深度面 | 注册字段 | 典型内容 | 与动态内容的关系 |
| --- | --- | --- | --- |
| 墙纸 | `wall.wallpaper` / `wallpaperId` | 绢布、墙纸、浅层山水与花纹 | 最远层，只承担底材 |
| 遗像 | `wall.portrait` | 用户像容、姓名、生卒信息 | 用户数据，不烘焙进主题素材 |
| 墙纸覆盖装饰 | `wall.wallpaperDecorations` / `wallpaperDecorationId` | 梅枝、荷叶、云纹、光环 | 位于墙纸之上、遗像周围 |
| 墙面造景 | `wall.scenery` / `wallSceneryId` | 月洞门、木格栅、石材立柱 | 独立于墙纸，可单独更换 |
| 造景附件 | `wall.sceneryDecorations` / `wallDecorationId` | 宫灯、壁灯、挂饰 | 安装在造景结构之上 |

地面陈设位于透视地坪之上，并继续拆为两个独立插槽：`groundMatId`（席毯）先铺设，`cushionId`（蒲团 / 坐垫）再叠放。席垫必须在画面中明显处于桌脚前方；按遮挡关系让席垫覆盖桌脚接地点，不得把席垫藏在桌下。左右镜头前景位于全部内容之前，负责摄影景深。每个插槽内部未来扩展候选时保持固定几何规格：席垫共用轮廓、画幅和显示比例；蒲团共用另一套轮廓、画幅和显示比例。候选只改变材质、颜色与纹样，保持摆放和镜头可比。

历史主题的 `backdropUrl` 只用于兼容。新主题必须使用 `wall` 契约。

## 4. 左右前景实例系统

前景分为定义与实例：

- `SceneForegroundDefinition` 是完整可复用素材，包含名称、侧别、预览图、PNG 和默认布局；
- `SceneForegroundInstance` 是一次入镜，包含独立位移、缩放、透明度和顺序；
- `SceneForegroundComposition.left/right` 分别保存左右实例数组。

数组没有数量上限。同一素材可以重复加入，同一侧也能混用多种素材。UI 的加减按钮只修改实例数组，Pixi 直接根据数组装配，不需要中间传递层。

## 5. 光源契约

每套主题必须提供 `lightRig`：

- `source`：主光在画面中的归一化位置；
- `sunAngle`：丁达尔光束推荐角度；
- `keyColor` / `ambientColor`：主光与环境色；
- `shadowDirection`：物体接触阴影离开光源的方向；
- `sunlightIntensity` / `godRaysIntensity`：推荐强度。

主题切换会应用与 `lightRig` 对应的 `preset.lighting`。用户之后仍可在环境面板里继续微调。

Pixi 顶光以 `lightRig.source` 为发光起点，`sunAngle` 控制光束斜向；修改主题入光方向时要同时核对阴影方向、墙面受光与地面反射。

## 6. PNG 生产要求

- 墙布 PNG 只覆盖墙面，从画布顶部延伸至 `y=0.70H–0.74H` 的墙地交界，不按整屏画幅绘制。iPhone 16 和 iPad 3:4 竖屏分别提供全幅构图，基准尺寸见设备构图规范。中心为动态遗像和纪念文字留出低对比区，并以近、中、多个远景形成纵深，不能用横图强行裁切或留空白边。
- 月洞门、格栅等整框造景按手机与 iPad 分别构图并从墙顶锚定，铺满对应的墙区画幅。中间开口应给遗像、文字和墙纸留下足够横向空间；不要为了收进墙区而缩窄中间开口。木构抵到画幅四边，格栅两侧用连续、不透明的纸面或实体材料衬底铺满画幅边缘，不得让墙纸和远景从格条间穿出，也不得留下白边或透明外框；只将明确设计的洞门开口设为透明。Pixi 按当前视口的墙地交界裁切框架溢出部分。
- 墙面灯饰等附件必须是真实透明 PNG，使用画布宽度比例和明确纵向锚点控制尺寸；不能带墙纸或遗像。
- 专属木地板使用覆盖完整地面平面的高分辨率不透明 PNG，并通过 Pixi 共享的地面透视网格统一投影，保证手机与 iPad 沿用同一相机方向；避免重复平铺带来的明显接缝。采用中等暖栗色、宽板和低对比细木纹，表面平滑并有柔和漆面层次。素材不烘焙太阳高光、光斑或投影；主光反射由渲染器作为方向统一的细长柔和反射带叠加，避免中央团状光晕。
- 其余素材必须具有真实透明通道，禁止用黑底或白底冒充透明。
- 遗像附件以遗像环直径作为缩放单位，不能写死屏幕像素。
- 席垫与蒲团 PNG 是相机匹配的透明独立器物图，体现与整体渲染稿一致的浅俯角和真实材质，不含地面背景、光效和自身投影。渲染器按视口宽度缩放并放在地面前景层，不再做透视变形。
- 墙灯 PNG 采用正视、左右对称的实体结构，表现灯框厚度、灯罩与安装位置；简洁不能做成平面贴纸。不画复杂挂链、长柄、墙体、侧视造型、发光或投影。
- 单侧镜头前景必须让中央和另一侧保持透明，边缘应自然羽化。
- 可拆分部件 PNG 使用中性受光，不烘焙主光、投影、光束、光晕、发光边缘、尘粒或散景。灯具素材只包含灯体；左右前景只包含植物、帘角等实物。最终场景光效由 Pixi 读取 `lightRig` 统一叠加，完整整体渲染稿不直接拆作部件。
- 素材中禁止烘焙用户遗像、姓名、纪念文字、供品、操作按钮。

## 7. 横向扩展流程

1. 在 `public/themes/<theme-id>/` 放入该主题的 PNG。
2. 在 `src/types.ts` 的 `WallBackgroundStyle` 联合类型加入 id；现阶段主题 id 与历史壁面 id 共用，兼容已有数据。
3. 在 `src/pixi/scene/themes/registry.ts` 注册一份 `SceneThemeDefinition`。
4. 在 `src/pixi/scene/components/registry.ts` 为每个可换插槽先注册一个选定部件，完成整体审计后再增加命名候选。
5. 配置 `defaultAssembly`，只保存部件 id 与左右前景实例。
6. 配置 `preset`，决定用户首次切换到该主题时采用的地面、桌布、案木和光照。

设置面板会自动读取注册表，选项数量和主题卡片无需再单独维护。
