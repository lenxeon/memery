# 东方美学与指导哲学

> **以丰其神** —— 让一器一物，都成为东方历史文化中闪烁的记忆

---

## 序：我们供奉的不是功能，是文明

用户走进这座堂轩，先看见的是一个空间；再细看，是一案、一瓶、一花、一果。
如果这些只是"可点击的图片"，那我们做的仍是一个粗糙的小游戏。

**我们的标准：任何一个元素被点开，都应该能讲出它的来历。**

- 这只瓶，为什么是这个曲线？（宋 · 梅瓶：小口、丰肩、瘦底，为储酒器，后为陈设器）
- 这朵花，为什么能供在案上？（菊：隐逸与晚节；莲：出尘与往生；梅：凌寒与气骨）
- 这颗果，为什么是柿子？（事事如意）
- 这块布，为什么叫"秋香金"？（宫廷织锦色名，出自色谱传统的色彩命名法）
- 这记钟声，为什么是 432Hz？（低回深远，古刹晨钟的听觉尺度）

**此谓"以丰其神"**：形已具，再以史、以礼、以文、以考据充之，神始丰。

## 一、礼 —— 礼者，理也，亦履也

礼不是繁文缛节，而是**把无形的哀思，变成有形的动作**。

### 1.1 祭祀的底层结构（贯穿产品动线）

| 环节 | 古法 | 产品映射 |
| --- | --- | --- |
| 斋戒 | 沐浴更衣，洁净身心 | 进入堂轩前的静默过渡（暗场 → 光起） |
| 陈设 | 案、位、器、供的方位 | 供案布局：牌位在中、瓶花在侧、果品在前、香炉居中 |
| 盥洗 | 净手 | 整理案台交互（拂尘、换水） |
| 上香 | 三炷为度 | 香炉点燃，三缕青烟缓起 |
| 献供 | 花、果、酒、馔 | 献花 / 供果面板 |
| 读祝 | 祝文（告于神主前之辞） | 祈愿：落笔成文，而非一句话留言 |
| 静默 | 无声之祭 | 熄屏留烛，只剩香与光 |
| 撤馔 | 礼成而退 | 供品随生命周期自然枯萎（花有枯荣） |

### 1.2 三条礼学戒律

1. **祭如在**（《论语·八佾》）：祭如在，祭神如神在 —— 空间必须营造"真的在场"，故光、烟、声必须真实连续，不能是静止贴图。
2. **哀而不伤**：哀痛有节，不渲染恐怖、不制造阴森。色用暖灰与沉香，不用纯黑、不用冷蓝。
3. **礼与其奢也宁俭**（《论语·八佾》）：宁可朴素，不可铺张。视觉上留白大于堆砌。

## 二、器 —— 器以藏礼，器以载道

### 2.1 花器（24 式）：一部微缩的中国陶瓷史

现存谱系中已包含大量名器形制，每一式都应配"物典"：

| 器名 | 形制源流 | 美学要点 |
| --- | --- | --- |
| `classic_meiping` 梅瓶 | 宋，小口丰肩瘦底，原为酒器 | 口小不能插花太多 —— 一枝为贵 |
| `song_mallet` 槌瓶 | 宋式，直颈圆腹，形如纸槌 | 极简至上的宋人审美 |
| `willow_guanyin` 观音柳枝瓶 | 净瓶，佛教供器 | 与莲、净水同案，寓往生 |
| `celadon_ru` 汝窑青瓷 | 北宋五大名窑之首，雨过天青 | 开片如蝉翼，色忌艳 |
| `qinghua_lotus` 青花莲纹 | 元明清青花，钴料呈色 | 缠枝莲纹为骨，白地蓝花 |
| `royal_blue_gold` 祭蓝描金 | 明清单色釉 + 描金 | 用于最庄重的场合 |
| `mutton_jade_ears` 羊脂玉双耳 | 仿玉质，双耳为古铜器遗制 | 温润、不透、如脂 |
| `archaic_ears` 仿古双耳 | 仿商周青铜耳制 | 铜器纹样（饕餮、蟠螭）的移植 |
| `painted_peony / painted_plum` 粉彩牡丹 / 梅花 | 清粉彩，没骨画法 | 牡丹富贵、梅花气骨 |
| 现代 12 式（棱瓶、涡轮瓶、螺旋塔瓶等） | 当代设计语言 | 用于"今人亦有其器"的表达 |

> **原则**：古器重"形制正确"，今器重"气质合礼"。古器不得臆造纹样，今器不得艳俗。

### 2.2 花卉（15 种）：一花一德

| 花 | 文化语义 | 供案用法 |
| --- | --- | --- |
| 牡丹 | 富贵、端严 | 祭礼之尊品，宜大供 |
| 莲 | 出淤泥不染；佛教往生 | 最重要佛门供奉，宜清水供养 |
| 菊 | 隐逸、晚节；亦为悼亡之花 | 秋祭、周年常见 |
| 梅 | 凌寒、气骨 | 冬祭、寒衣节 |
| 水仙 | 清、仙、岁朝清供 | 年节案头 |
| 兰（蝴蝶兰） | 幽、君子之德 | 素供，宜配素器 |
| 百合 | 百年好合、纯洁 | 通用，宜白 |
| 康乃馨 | 慈母之爱（本土化后语义） | 通用，宜暖色 |
| 玫瑰 / 马蹄莲 / 郁金香 | 西来之花，今已成俗 | 保留，但标注"外来品种" |
| 铃兰 / 绣球 / 雏菊 / 向日葵 | 当代表达 | 个人化，纪念性格鲜明者 |

> **原则**：花有枯荣（生命周期）。花会谢，是礼的一部分 —— **不许做成永不凋零的塑料感**。

### 2.3 果品（18 样）：谐音、象征与时令

| 果 | 寓意 | 时令/场 |
| --- | --- | --- |
| 桃 | 寿（蟠桃、西王母） | 寿诞、周年 |
| 柿 | 事事如意 | 四季 |
| 橘 / 柑 | 吉（谐音） | 年节 |
| 苹果 | 平安 | 通用 |
| 香橼 | 清供之品，取其香 | 文人案头 |
| 葡萄 | 多子、丰饶 | 家族兴旺 |
| 柚 | 佑（谐音）、团圆 | 中秋、年节 |
| 龙眼 / 荔枝类 | 团圆、甜蜜 | 南方宗族常见 |
| 梨 | **慎用**：谐音"离" | 需标注提示，不建议独供 |

> **原则**：供果讲"三果五果"之数，取奇数（阳数）；忌单样独陈，忌腐败失真。

### 2.4 案、布、壁、地

| 类 | 六式 | 美学依据 |
| --- | --- | --- |
| 案木 | 黄花梨（明式名木，鬼脸纹）、胡桃、樱桃、白橡 | 明式家具尚"线"，不尚"饰" |
| 桌布 | 秋香金（宫廷织锦）、靛青蓝（禅意粗麻）、朱砂红（吉祥）、月魄白（素绢）、黛螺绿（松柏长青）、紫檀金（沉香庄严） | 色名本身即文化 |
| 壁景 | 晨光拱窗、紫檀花格、皇家帷幔、铜镜、青砖影壁、宝相莲台 | 影壁为礼制建筑，花格为透光而不透人 |
| 地坪 | 桧木、胡桃、人字拼、榻榻米（素席）、汉白玉 | 人字拼为传统木作，汉白玉为礼制建材 |

## 三、乐 —— 乐以和神，声律即礼律

### 3.1 五声音阶：宫商角徵羽

中国传统音乐以五声为骨，无半音之尖锐，故听感平和。产品中的古琴曲目（`pentatonic_zither`）严格取自五声音阶 —— **任何欢快的、进行曲式的、电子舞曲感的旋律都不得出现**。

### 3.2 四支环境曲

| 曲 | 意象 | 声学设计 |
| --- | --- | --- |
| 空灵钵韵 | 528Hz 祈福疗愈 | 纯铜颂钵泛音，余音悠长 |
| 幽篁清风 | 修竹甘露 · 禅寺木鱼 | 竹风 + 水滴 + 木鱼，如临山间精舍 |
| 晨钟远山 | 梵音古刹 | 432Hz 大钟低回，深远 |
| 五音琴韵 | 高山流水 · 宫商角徵羽 | 古琴泛音，断续幽微 |

### 3.3 七种法音（交互反馈）

瓷碰（置瓶）、擦火（点烛）、置木（摆件落案）、熄灭（熄烛）、风铃（风起）、颂钵（敲击）、古琴泛音（特殊节点）。

> **原则**：法音即反馈。所有交互都要有"物性"的声音 —— 木质沉、瓷质清、金属长。**禁止使用 UI 通用的"叮咚"提示音。**

## 四、诗、赋 —— 文以足言，言以足志

### 4.1 悼亡的文学传统（内容库的根）

| 传统 | 代表 | 本产品对应 |
| --- | --- | --- |
| 《诗经》 | 《蓼莪》"哀哀父母，生我劬劳" | 父母之祭的引文 |
| 诔 / 哀辞 | 潘岳《悼亡诗》 | 配偶之祭 |
| 祭文 | 韩愈《祭十二郎文》 | 手足、晚辈之祭 |
| 词 | 苏轼《江城子·乙卯正月二十日夜记梦》 | 忌日、梦境 |
| 记 | 归有光《项脊轩志》"庭有枇杷树" | 家族空间的叙事范本 |
| 行状 | 记述生平之文 | **纪念馆的"生平"字段即为行状** |
| 墓志铭 | 志 + 铭 | 牌位铭文、碑刻导出 |

### 4.2 落到产品

- **祈愿不是留言，是"祝文"**：提供文体模板（四言、楚辞体、散文体），让不会写的人也能说出体面的话。
- **纪念馆不是资料卡，是"行状"**：引导用户按 籍贯—生卒—行迹—德行 的结构写。
- **牌位不是名字，是"铭"**：字数、称谓、字体（宋体/隶书/楷体）都有讲究。

- **植物**：缠枝莲、宝相花（集众花之美，理想之花）、忍冬、卷草、松柏、灵芝（如意）

## 六、考古学与历史学：让器物"可考"

### 6.1 每件器物应提供的四段信息

1. **名**：正名与别名（如"梅瓶"亦称"经瓶"）
2. **形**：形制特征（口、颈、肩、腹、足）
3. **代**：通行年代（宋 / 元 / 明 / 清 / 当代）
4. **工**：材质工法（汝窑开片、青花钴料、鎏金、错金银、剔犀、缂丝）

### 6.2 断代与谱系

器物之间存在**谱系**：青铜 → 陶 → 瓷；单色釉 → 青花 → 五彩 → 粉彩；席 → 砖 → 木 → 石。
产品中的"专项审计展台"本质就是**谱系对比台** —— 它不应只是开发调试工具，而应被建设为**面向用户的"器物谱系陈列"**。

## 七、美学总纲（可执行的十条）

1. **留白胜于堆砌**：界面空白率不低于 30%，案面留三分空。
2. **五色为正**：青、赤、黄、白、黑为正色，其余为间色；正色用于礼，间色用于情。
3. **素以为绚**：先有素底，再有纹饰。禁止高饱和渐变。
4. **气韵生动**：一切都要动 —— 烟、火、光、尘、花瓣。静止即死。
5. **哀而不伤**：色调沉而不暗，明度不超过 70%，饱和度不超过 60%。
6. **中正对称**：供案陈设以中轴为尊，牌位居中，瓶花成双。
7. **虚实相生**：光（丁达尔）、烟、影是"虚"，器、案、花是"实"，虚实各半。
8. **因时制宜**：晨清明、暮温润、夜静穆，三时各有光色规范。
9. **器必有声**：交互必带物性音效（见 3.3）。
10. **文必有体**：凡文字输出（祝文、碑铭、行状）必依文体，不写大白话弹窗。

## 八、价值观与社会责任

- **慎终追远，民德归厚**（《论语·学而》）：丧祭之礼的社会功能，是本产品的存在理由。
- **不消费悲伤**：不做排行榜、不做"榜单冲刺"、不做限时诱导、不做签到领奖。付费只用于器物与空间扩展。
- **绿色永续**：数字供奉替代实物焚烧，减少纸钱与香烛的环境负担。
- **尊严与隐私**：纪念馆可设为私密；逝者信息不出售、不外放、不做广告推荐。
- **真实与防伪**：水印机制（`pixi/assets/security/Watermark.ts`）保障内容不被盗用，也是对逝者的尊重。
- **文化普惠**：让年轻人自然习得器物、纹样、礼仪知识，是最不费力的文化传承。

## 九、反面清单（明确禁止）

| 禁止 | 原因 |
| --- | --- |
| 恐怖、阴森、鬼怪元素 | 违"哀而不伤"，是对哀思的冒犯 |
| 高饱和霓虹、赛博风、玻璃拟态 | 与庄重相悖，破坏朝夕三时的沉静 |
| 通用 UI 提示音（叮、咚、Click） | 破坏"器必有声" |
| 任务、打卡、签到奖励、成就徽章 | 把祭礼变成游戏，违背产品伦理 |
| 弹窗广告、诱导付费、消费排行 | 不消费悲伤 |
| 臆造古器纹样、错用断代 | 错纹比无纹更伤人 |
| 永不凋零的塑料花、永不燃尽的烛 | 失去时间感，即失去哀思的容器 |
| 把逝者做成可炫耀的数值 | 尊严优先 |
