## 二、本包文件结构与使用方式

```
docs/软著申请/
├── 00-申请材料总览与填表说明.md   ← 本文：清单、填表字段、排版规范、驳回点自检
├── 01-用户操作手册.md              ← 文档鉴别材料（主选）：面向最终用户的完整操作说明
├── 02-软件设计说明书.md            ← 文档鉴别材料（备选/补充）：架构、模块、数据结构、关键技术方案
├── 03-源程序-前30页.md             ← 程序鉴别材料（第 1—30 页）
└── 04-源程序-后30页.md             ← 程序鉴别材料（第 31—60 页）
```

**使用流程**：

1. 按第 1 步：把 `01-用户操作手册.md`（或加 `02-软件设计说明书.md`）排版成 A4 PDF，每页不少于 30 行，页眉写「暖念纪念场景模拟软件 V1.0」，页脚标页码，确保总页数 ≥ 60 页；不足 60 页则全部提交。
2. 按第 2 步：把 `03`、`04` 两个源程序文件合并排版成 A4 PDF，每页不少于 50 行，页眉同上，页码连续 1—60。
3. 按第 3 步：登录填报系统，照本文第三节逐字段填写并打印签章。
4. 按第 4 步：用本文第六节「驳回点自检清单」逐条核对后再寄出。

> 排版提示：Markdown 转 PDF 可用 Pandoc（`pandoc 01-用户操作手册.md -o 手册.pdf --pdf-engine=wkhtmltopdf`）或先粘入 Word 再导出 PDF；代码类文件建议统一用等宽字体（Consolas / 宋体小四），字号以每页 50 行为准自行微调。

### 3.1 功能描述（建议文案，约 700 字；表单要求 500—1300 字）

本软件为面向纪念、追思与祈福场景的交互式虚拟空间模拟软件，以 iOS、Android 移动端为主并兼容桌面浏览器，无需专用硬件。软件以中式堂轩与供案为空间原型，构建可进入、可操作的 2.5D 纪念场景，主要功能包括：一、空间与陈设，提供 6 式壁景、6 种地坪、4 种案木与 6 式桌布的组合配置，供案、遗像牌位、花器、果盘、香炉、烛台、茶杯、颂钵等器物可在案上自由拖摆放位，支持触摸拖拽、长按查看与一键复位；二、供奉交互，支持 15 种花卉敬献与一键布设、18 样果品供盘、蜡烛点燃与熄灭、香炉上香、祝文祈愿提交、颂钵击响，并可按「现实/演示/极速」流速模拟花开花谢与香烛燃尽的生命过程；三、光影造境，提供日照总闸、白昼/黄昏/夜色三时辰切换与系统时钟跟随，丁达尔光束浓度与入射倾角调节，微风吹拂强度调节，浮尘与落瓣粒子效果；四、名录与纪念，支持堂轩筹建、堂轩名录切换、遗像与纪念寄语编辑、守护天数与祈福计数；五、器物典故，内置 58 条花、果、器、纹样文化档案，长按器物即可查阅；六、声律，内置 4 支五声音阶环境曲与 7 种法音音效，可独立开关与音量调节；七、场景设置，提供画质、音效、粒子浓度、时间流速与视角偏好的统一配置；八、数据与隐私，场景配置默认本地保存并支持清空重置，肖像与寄语等敏感内容默认不出本机。九、状态可视，花器、果盘、香烛的剩余状态在案面与面板上同步呈现，便于随时查看与更换；十、引导与容错，首次进入提供布设指引与器物说明，配置异常时回退至默认堂轩，避免空白场景。软件运行期无服务端交互，离线亦可正常使用。

### 3.2 技术特点（建议文案，约 700 字；表单要求 500—1300 字）

一、渲染架构采用 UI 与渲染二分：React 19 负责交互与面板，PixiJS 8.20（WebGL）负责场景绘制，二者仅通过统一数据契约通信，杜绝渲染层与业务层耦合。二、真 2.5D 视差：建立背景、遗像、地坪、供案、器物、烟尘、灯光七层容器，各层按不同系数逐帧阻尼插值，产生指针或触摸跟随的进深视差。三、透视地坪使用主题自带的完整透视 PNG，透视已烘焙在图像中；Pixi 将其作为普通精灵等比摆放并裁切以适配手机地坪画幅，不使用网格投影或 UV 映射，配合 ColorMatrixFilter 实现昼夜色温与明暗氛围。四、矢量纹理管线：器物、花卉、果品与供案均以参数化 SVG 描述，经离屏 Canvas 超采样（2.0—2.5 倍）光栅化为 GPU 纹理并全局缓存，一次生成、多处复用，显著降低移动端首屏开销。五、光照与粒子：丁达尔光束以几何形态一次烘焙成贴图、运行时仅做加色混合与相位变换；浮尘、落瓣、青烟、烛焰均为对象池化粒子，配合 BlurFilter 与 add 混合实现柔光与光雾。六、生命仿真：统一世界时钟推进含苞—盛开—微凋—枯萎—撤下的生命周期，并按流速节流提交，避免高频重排。七、音频以 Web Audio 实时合成五声音阶环境曲与法音，无音频文件依赖，便于移动端首包瘦身。八、移动端适配：视口与设备像素比自适应，触摸与鼠标事件归一，安全区留白与竖屏布局优化，保证小屏可用性。九、矢量模板嵌入几何隐写数字水印，可校验溯源。十、性能闭环：贴图与粒子池化、脏标记重绘、按需生成与缓存淘汰，目标 60FPS，并可按设置降低粒子浓度与超采样倍率。
