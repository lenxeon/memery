## 1 前言

### 1.1 编写目的

本手册面向「暖念纪念场景模拟软件 V1.0」的最终使用者，系统说明软件的安装启动、界面布局、全部功能的操作方法与注意事项，使用户能够在无需培训的条件下独立完成：

- 进入并布置一座虚拟纪念堂轩；
- 完成献花、供果、点烛、上香、击颂钵、读祝等一整套追思动作；
- 调节光影、时辰、地坪、壁景、桌布、案木等环境要素，营造合宜的空间氛围；
- 筹建与切换堂轩、编辑遗像与纪念寄语；
- 查阅器物典故，理解一器一物的文化来历。

本手册同时作为计算机软件著作权登记的文档鉴别材料。

## 2 软件概述

### 2.1 产品定位

本软件是一套运行于通用 Web 浏览器的**交互式纪念场景模拟软件**。它以中式堂轩与供案为空间原型，通过实时渲染构建可进入、可操作的 2.5D 纪念空间，使身处异地的用户可以随时完成一次庄重、完整、有文化依据的追思与祈愿。

软件坚持三条设计戒律：

1. **祭如在** —— 光、烟、声必须真实连续，绝不使用静止贴图敷衍；
2. **哀而不伤** —— 色取暖灰沉香，不用纯黑冷蓝，不用高饱和刺激色；
3. **礼与其奢也宁俭** —— 庄重优先于炫目，不做打卡、排行、诱导消费。

### 2.3 运行环境

| 类别 | 要求 |
| --- | --- |
| 硬件（客户端） | 支持 WebGL 的通用计算机或移动设备；建议内存 ≥ 4GB、显存 ≥ 512MB |
| 操作系统 | Windows 10 及以上 / macOS 12 及以上 / Linux（桌面）/ iOS 15 及以上 / Android 10 及以上 |
| 浏览器 | Chrome 100+、Edge 100+、Safari 15+、Firefox 100+（需启用 WebGL 与 Web Audio） |

### 2.4 软件构成

软件由三层构成：

- **交互层**（React 19）：登录页、堂轩名录、献花 / 供果 / 祈愿面板、环境设置抽屉、典故卡等；
- **渲染层**（PixiJS 8.20 / WebGL）：七层 2.5D 视差场景，包含背景墙、遗像牌位、透视地坪、供案、案上器物、烟尘与灯光；
- **数据层**：业务类型定义、预置场景数据、器物典故档案；运行期状态保存在浏览器本地存储。

## 3 安装、启动与退出

### 3.1 使用已部署站点（普通用户）

1. 在浏览器中打开服务方提供的网址；
2. 等待首屏资源加载完成（首次约需数秒，取决于网络）；
3. 出现登录页即表示可正常使用，无需安装任何客户端或插件。

### 3.2 本地构建与部署（维护人员）

前置条件：安装 Node.js 18 或更高版本。

```bash
# 1. 安装依赖
npm install

# 2. 本地开发运行（默认 http://localhost:3000）
npm run dev

# 3. 生产构建，产物位于 dist/
npm run build

# 4. 预览构建产物
npm run preview
```

部署时将 `dist/` 目录整体上传至任意静态服务器或 CDN 即可；软件不依赖后端服务，亦无需数据库。

> 说明：构建需 Node.js ≥ 18。若使用更低版本（如 Node 14），构建工具会因语法不兼容而报错，请先升级运行时。

### 3.3 退出与数据

- 关闭浏览器标签页即可退出；
- 未登录状态下的操作不写入服务端；
- 登录态、堂轩列表、当前主奉保存在浏览器本地存储（`localStorage`），键名分别为 `memery_current_user`、`memery_memorial_halls`、`memery_current_hall_id`；
- 清除浏览器数据将导致上述本地信息丢失，**建议在正常使用中不要清理站点数据**；
- 更换设备或浏览器时，本地保存的堂轩列表不会自动同步（当前版本为纯前端存储）。

## 4 快速上手：十分钟完成一次追思

以下步骤覆盖最常用的完整动线，初次使用者按此执行即可。

**第 1 步 · 登录**

打开首页 → 选择「手机号」通道 → 输入手机号码 → 选择「验证码登录」→ 输入验证码（演示环境验证码为 `8866`）→ 勾选同意服务协议 → 点击「登录」。

**第 2 步 · 进入堂轩**

登录后进入堂轩空间；若为首次使用，点击「筹建新堂」录入纪念对象信息（详见 6.2），保存后自动进入该堂轩。

**第 3 步 · 瞻仰与整备**

- 画面正中：遗像牌位与堂号题名；
- 画面下方：明式供案，其上默认陈设常规五供；
- 鼠标在画面中移动，场景产生 2.5D 视差微动，可环视空间。

**第 4 步 · 完成一套礼**

| 动作 | 操作 | 界面位置 |
| --- | --- | --- |
| 献花 | 点击底部「供台功能」→「献花」→ 选花 →「敬献」 | 底部控制坞 |
| 供果 | 「供果」→ 选果 →「敬奉新果盘」 | 底部控制坞 |
| 点烛 | 「点烛」一键点亮案上双烛；或直接点击案上烛台 | 底部控制坞 / 画布 |
| 上香 | 直接点击案上香炉 | 画布 |
| 祈愿 | 「祈愿」→ 填写祝文或选快捷词 →「呈献祈愿」 | 底部控制坞 |
| 击颂钵 | 直接点击案上颂钵 | 画布 |

**第 5 步 · 营造氛围（可选）**

点击顶栏设置（⚙）打开「场景光影与环境造境」抽屉，依次设定：日照总闸 → 时辰（白昼 / 黄昏 / 夜色）→ 丁达尔光线浓度 → 壁景 → 地坪 → 桌布 → 案木 → 环境曲。设定即时生效，无需保存。

**第 6 步 · 礼成静默**

完成祈愿后可关闭面板，留烛静默片刻；离开时直接关闭页面即可，陈设与氛围设置随本地存储保留。

## 6 功能操作详解

### 6.1 登录与注册

**进入方式**：首页 / 顶栏「登录注册」。

**支持通道**

| 通道 | 说明 |
| --- | --- |
| 手机号 | 支持「验证码登录」与「密码登录」两种模式，提供多个国际区号可选；演示环境验证码为 8866 |
| 微信 | 支持一键登录与二维码两种模式 |
| Apple | Apple 账号登录 |

**操作步骤**

1. 选择登录通道；
2. 手机号通道：输入号码 → 选择验证码或密码模式 → 填入验证码 / 密码；
3. 勾选「已阅读并同意服务协议」（未勾选无法通过校验）；
4. 点击登录 → 进入堂轩空间；
5. 登录成功后，系统记录登录方式、守护天数与祈福次数。

**注意事项**

- 未勾选协议时登录按钮不可用，并给出提示；
- 登录态保存在本地，重新打开浏览器一般无需重复登录；
- 当前版本登录为前端流程，未接入后端账号体系，请勿使用真实敏感密码。

### 6.2 堂轩名录与筹建新堂

#### 6.2.1 堂轩名录

**进入方式**：堂轩空间内的名录入口（卡片列表）。

**界面构成**

- 两个页签：**我创建的**、**我瞻仰过的**；
- 卡片信息：堂号、遗像、与纪念对象的关系、生卒年、守护天数、香火（祈福）次数；
- 卡片操作：
  - 「进入案台」：切换当前主奉堂轩；
  - 「分享」：生成并复制邀请文案到剪贴板；
  - 空状态提供筹建引导。

#### 6.2.2 筹建新堂

**操作步骤**

1. 点击「筹建新堂」；
2. 填写纪念对象**姓名**；
3. 选择**关系**（祖母、祖父、慈母、慈父、外祖父母、恩师、挚友、灵宠、先贤等 10 项之一，选中后系统自动推荐堂号）；
4. 确认或修改**堂号**；
5. 填写**生卒年**；
6. 选择**遗像**：可从 5 张预设中选，也可粘贴自定义图片地址；
7. 保存 → 自动进入新堂轩。

**说明**：关系与堂号对应传统称谓规范；遗像支持外链图片地址，建议使用清晰正面照。

### 6.3 纪念像容与寄语编辑

**进入方式**：点击画布中的遗像 → 弹出编辑窗。

**可编辑项**

| 字段 | 说明 |
| --- | --- |
| 主标题 | 牌位主铭，通常为称谓或名讳 |
| 副标题 | 副铭或纪念寄语 |
| 遗像 | 选择预设图，或填入图片地址 |

**操作步骤**：点击遗像 → 修改字段 → 保存 → 画布中的牌位与遗像即时更新。

### 6.4 献花

**进入方式**：底部控制坞 →「献花」。

**页签一：敬献**

| 项 | 内容 |
| --- | --- |
| 可选花材 | 牡丹、百合、清莲、白菊、玫瑰、梅、向日葵、康乃馨、马蹄莲、郁金香、水仙、铃兰、蝴蝶兰、绣球、雏菊（15 种） |
| 敬献 | 选中花材后点击「敬献」，系统自动计算不重叠的摆放位置并落于案上 |
| 一键布设十捧香花 | 批量按序求解摆位，一次性布设十捧 |
| 清空全部献花 | 移除本次新增的全部献花 |

**页签二：瓶器**

- 分别指定**左瓶**与**右瓶**的花材与器形；
- 器形包含 12 款现代器与经典名瓷共 24 式；
- 每个选项旁显示典故角标，可点击查看该器物的文化档案。

**注意事项**

- 献花后的花材具备生命周期（含苞 → 盛开 → 微凋 → 枯萎 → 撤下），速率由「生机与岁月流速」决定；
- 摆位由算法自动求解，避免器物重叠；手动拖动可覆盖自动位置。

### 6.6 点烛与上香

**烛台**

- 点击案上烛台：点燃；再次点击：熄灭；
- 燃尽后再点击：换上新烛（重置燃烧进度）；
- 底部控制坞「点烛 / 熄烛」可一键操作案上双烛；
- 「呈献祈愿」时会自动点亮双烛与香炉。

**香炉**

- 点击案上香炉：上香；再次点击：熄灭；
- 燃尽后再点击：换上新香；
- 香炉燃起后升起三缕高低错落的青烟，尾部渐隐。

**微风吹拂**

- 位置：设置抽屉 →「烛火与清香火苗」→ 微风吹拂滑杆；
- 范围：−1 ~ +1，负值向左偏、正值向右偏；
- 效果：影响火苗摆动幅度与青烟飘散方向。

### 6.7 祈愿祝文

**进入方式**：底部控制坞 →「祈愿」。

**操作步骤**

1. 在文本区撰写祝文（祭文、寄语、追思短文均可）；
2. 或使用面板提供的四例快捷祈愿词作为起句；
3. 点击「呈献祈愿」；
4. 系统同时点亮案上双烛与香炉，并记录一次祈福计数。

**说明**：祝文为用户亲笔内容，软件不代写、不自动生成不可编辑的文本；传统文化中祝文有文体之别（四言、楚辞、散文、词体），本版本提供自由撰写入口。

## 7 典型业务流程

### 7.1 一次完整的追思动线

```
静心（暗场入室，关闭日照总闸）
  → 拂案（拖拽整理案上摆位）
  → 上香（点击香炉，三炷）
  → 献花（献花面板 → 选花 → 敬献）
  → 供果（供果面板 → 选果 → 敬奉新果盘）
  → 燃烛（点击烛台或底部「点烛」）
  → 读祝（祈愿面板 → 撰写祝文 → 呈献）
  → 静默（熄屏留烛，留烛片刻）
  → 礼成
```

### 7.2 忌日追思

1. 进入对应堂轩（堂轩名录 →「进入案台」）；
2. 时辰选「静谧微夜」或「暖调黄昏」；
3. 关闭日照总闸，仅留烛火香光；
4. 献上故人生前所好之花与果；
5. 撰写忌日祝文并提交；
6. 开启环境曲（推荐「空灵钵韵」或「晨钟远山」），留烛静默。

### 7.3 岁时之祭（清明 / 中元 / 寒衣 / 冬至 / 除夕）

以清明为例：

| 步骤 | 操作 |
| --- | --- |
| 时辰 | 白昼晨光 |
| 壁景 | 晴岚映曜或暮林晚钟 |
| 花材 | 白菊 |
| 果品 | 青团、素供一类清淡供品（按实际选择相近果品） |
| 光束 | 开启丁达尔，浓度调至中等 |
| 祝文 | 撰写清明追思短文 |

### 7.4 家族共祭（异地协作）

1. 由创建者在堂轩卡片点击「分享」，复制邀请文案发给亲属；
2. 亲属按文案进入同一堂轩（当前版本在本地存储中保留「我瞻仰过的」记录）；
3. 各自献花、供果、点烛、读祝；
4. 祈福次数与守护天数随操作累计。

## 8 常见问题与故障处理

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 页面空白 / 长期加载 | 网络缓慢或资源未就绪 | 刷新页面；检查网络 |
| 场景不显示或黑屏 | 浏览器未启用 WebGL / 硬件加速 | 在浏览器设置中启用硬件加速与 WebGL；更换 Chrome / Edge |
| 画面卡顿 | 设备性能不足或开启过多特效 | 调低丁达尔浓度、关闭浮尘密集效果、关闭落瓣 |
| 无声音 | 顶栏音效处于静音，或浏览器自动播放策略限制 | 点击 🔊 恢复；在页面上先有一次点击交互后再播放 |
| 拖动无反应 | 指针未落在器物可命中区（如香炉命中区较窄） | 对准器物主体再拖动 |
| 长按未弹出典故 | 按压时长不足 0.5 秒或中途移动 | 按住静止约 0.6 秒后释放 |
| 花忽然消失 | 生命流速较高，花已枯萎撤下 | 将流速调为「永生停驻」或重新献花 |
| 换设备后堂轩不见了 | 数据保存在原浏览器的本地存储 | 在原设备 / 原浏览器中使用，或重新筹建 |
| 遗像不显示 | 图片地址失效或跨域受限 | 更换为可访问的图片地址 |
| 构建报错（Node 14） | 运行时版本过低 | 升级 Node.js 至 18 及以上 |
