## 一句话总纲

**纪念故人，只是最基础的功能。**
每一个花、每一个瓶、每一个符号，都是东方历史文化里闪烁的记忆片羽。
用户抚过一器一物时，应当同时触到**美学、礼学、历史学、考古学**的厚度 —— 此为**以丰其神**。

## 阅读顺序建议

新同学：`01 立项` → `02 美学哲学` → `04 编程规范` → `03 功能方向`。
先知道为什么做（01），再知道做成什么样（02），然后知道怎么写（04），最后知道往哪走（03）。
