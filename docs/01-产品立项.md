# Memery 产品立项文档

> 虚拟线上祭祀祈福台 · 以东方礼乐文明为骨，以思念为魂

---

## 一、我们在解决什么

### 1.1 现状：三个真实的断裂

| 断裂 | 表现 |
| --- | --- |
| **空间的断裂** | 游子异乡、漂洋过海、加班的深夜 —— 想上一炷香时，没有一处可供俯身的案前 |
| **仪式的断裂** | 年轻人想表达哀思，却不知道该做什么动作、该说什么话，只剩下转发一支蜡烛的表情 |
| **文化的断裂** | 现有的线上祭扫产品多为"模板页 + 献花按钮 + 付费排行榜"，器物无名、礼节无据、纹样无源，把最庄重的文明仪轨做成了粗糙的小游戏 |

### 1.2 被忽略的关键事实

**纪念故人，只是最基础的功能。**

一个花瓶的曲线来自宋人的梅瓶，一朵莲的寓意来自佛教的往生观，一记钟声的频率锚在 432Hz，一缕香烟要走三道才合古法 —— 这些都是**东方历史文化中闪烁的记忆**。

用户真正需要的，是一个能让他在**抚过一器一物时，同时触到美学、礼学、历史学、考古学厚度**的地方。我们在做的不是"网上扫墓"，而是一座**可被使用的文明记忆馆**。

## 二、产品定位

> **Memery：一座可进入的中式纪念空间。以器载礼，以礼安魂，以文丰神。**

- **不是**：社交平台、游戏化打卡、付费攀比榜、电子讣告生成器。
- **是**：一处庄重、私密、考究的中式堂轩；一套可操作的祭祀礼仪；一部能翻开的东方器物志。

### 2.1 三层价值主张

| 层 | 主张 | 落到产品 |
| --- | --- | --- |
| **形** | 以礼立形 | 空间按堂轩制式陈设：案、瓶、花、果、香、烛、位（牌位）、影（遗像），方位与层次有据 |
| **器** | 以器载道 | 24 式瓶、15 种花、18 样果、6 式桌布、6 式壁景、6 种地坪、4 种名木 —— 每一件都能说出出处 |
| **神** | 以文丰神 | 每一器附典故、断代、纹饰谱系；祈愿成文、生平成状、岁时成礼 |

## 三、为谁而做

| 用户 | 核心诉求 | 我们给什么 |
| --- | --- | --- |
| **异地游子** | 无法归乡，需要一个随时可去的"案前" | 随时可进入的堂轩，三时流转（晨 · 暮 · 夜），一炷香的时间就够了 |
| **家族守护者** | 族谱散佚、故事失传，怕后代不记得 | 纪念馆 + 生平行状 + 家族名录，记忆可传承、可接续 |
| **年轻一代** | 有情感、无仪轨，不知如何表达 | 把礼仪做成**可跟随的动作**：盥手 → 上香 → 献花 → 供果 → 读祝 → 静默 |
| **海外华人** | 文化身份的锚点 | 一整套中式美学与礼制语境，是身份认同的具象载体 |
| **公共悼念场景** | 突发灾难、公众人物逝世的集体哀思 | 可开放、可守护、有节制的公共纪念空间 |

## 四、核心场景

1. **日常省视**：晨昏定省，进堂轩点一盏烛，坐片刻。不喧哗，不打卡。
2. **忌日与生辰**：周年之祭，三献礼完整走一遍，写下一段祝文。
3. **岁时之祭**：清明、中元、寒衣、冬至、除夕 —— 场景随节气自动换装（壁景、光色、供品）。
4. **临时悼念**：噩耗传来，快速建馆、上香、留言，无需注册门槛。
5. **家族共祭**：异地亲人同时进入同一个堂轩，各自献一物，合成一案。

## 五、产品立意（六根支柱）

### 5.1 人 · 构建人
生者需要一个**能安放动作**的地方。思念若无动作承载，就会悬空。我们提供动作：擦拭、上香、换水、添果、读祝。动作即疗愈。

### 5.2 故人
逝者不是数据条目，而是一个有生平、有声音、有偏好、有故事的人。**遗像 + 牌位 + 行状**三件套，构成一个人的完整在场。

### 5.3 思念
思念需要**时间感**：晨光、暮色、夜烛，香有三炷、花有枯荣、烛有明灭 —— 让时间本身成为哀思的容器。

### 5.4 社会责任
- **慎终追远，民德归厚**：这是儒家对丧祭之礼的核心判断，也是本产品的社会价值根基。
- **绿色与永续**：以数字供奉替代部分实物焚烧，减少纸钱香烛的环境负担。
- **文化普及**：让年轻人自然习得器物、纹样、礼仪知识，是最不费力的文化传承。
- **尊严与纯粹**：不做排行榜、不做诱导消费、不做弹窗广告、不做签到奖励 —— **庄重即底线**。

### 5.5 价值观
哀而不伤（《论语》对《关雎》的评价）、祭如在（《论语·八佾》）、事死如事生（《中庸》）、礼与其奢也宁俭（《论语》）。产品的一切克制，都出自这四条。

### 5.6 传承
记忆只有被**讲述**才不会死。我们要做的，是把"记得"变成一种可持续的行为：可写、可传、可续、可考。

## 七、差异化

| 维度 | 常见线上祭扫 | Memery |
| --- | --- | --- |
| 器物 | 通用图素材，无名无源 | 有名、有形制、有断代、有出处 |
| 仪式 | 点按钮 | 可跟随的礼仪动线 |
| 美学 | 模板化黑金卡片 | 宋明堂轩制式，留白与克制 |
| 声音 | 无或廉价音效 | 实时合成的正律法音 |
| 商业 | 排行榜 + 道具付费 | 庄重优先，付费仅限器物与空间扩展 |
| 文化 | 无 | 以礼、器、乐、诗、赋贯穿 |

## 八、成功指标

| 类 | 指标 | 说明 |
| --- | --- | --- |
| 情感 | 单次停留时长、回访问隔 | 哀思需要停留，而非点击即走 |
| 仪式 | 完整礼序完成率 | 有多少人走完 上香→献花→供果→读祝 |
| 文化 | 物典阅读率、祝文提交率 | 衡量"以文丰神"是否真的发生 |
| 传承 | 家族成员共建率、代际账号 | 记忆是否被接续 |
| 工程 | 60FPS 达标率、冷启动时长 | 庄重感建立在流畅之上（详见编程规范） |
