> 历史审阅资料：本目录中的地面底材仅作早期材质参考，不是当前运行时地坪资产。当前主题必须使用透视已绘入 PNG 的完整地坪图，由 Pixi 直接显示。

- `01-wallpaper.png`：不透明墙纸；独立山水远景、暖绢底色，保留遗像和文案留白。
- `02-wall-scenery.png`：RGBA 木质月洞框；框架外与洞门开口透明，侧格栅铺不透明素纸。
- `03-altar-table.png`：RGBA 供桌；透明背景，无供品与场景投影。
- `04-floor-base.png`：不透明早期地面材质审阅母版；不作为当前运行时地坪图。

所有图以用户提供的整体渲染稿为视觉参考。PNG 不包含后期光斑、地板高光、前景散景或接触投影；Pixi 页面继续负责布局和运行时效果。

生产资源副本位于 `public/themes/classic_dawn/`：墙纸在 `wallpapers/phone/`，木框在 `wall-scenery/phone/`，供桌在 `table/`，地板在 `floor/`。页面组合后仍需由用户截图审计。
