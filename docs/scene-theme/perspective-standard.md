# Memery 素材统一透视规范

初版日期：2026-10-27；主题1供桌基线于2026-10-29按用户要求修订。本文用于素材生成、替换和测量验收；主题1与主题4已按新的31.4 CSS px桌面纵深目标更新，组合观感仍以用户审核为准。

## 统一机位

采用**正面居中、轻俯视约 15°**的观感，允许 13°–17°的小幅差异。无左右偏转、无滚转，不使用广角夸张；建筑垂直线保持竖直。15°是后续素材的目标机位，不是从现有 PNG 反算出的真实摄影参数。

以 iPhone 16 的 393×852 CSS 画布为准：

| 项目 | 统一目标 |
|---|---|
| 透视消失点 | `x=0.50W，y=0.58H`，约 `(196.5, 494)` |
| 透视地平线 | 经过消失点的水平线；不要画成可见装饰线 |
| 墙地交界 | 通用主题 `y=0.732H`，约 `624 CSS px` / `1870 px` 输出像素；它与透视地平线是两个位置 |
| 消失点审核容差 | 横向 `±0.02W`、纵向 `±0.02H`，在最终组合画布中比较 |

地面纵向接缝、供桌台面左右纵深边、席垫左右纵深边的延长线，应趋向同一个消失区域。各 PNG 的留白、裁切和摆放不同，因此不能直接比较它们源图里的消失点坐标，必须放进同一整体构图后比较。15°用于描述浅俯观感，消失点位置用于约束画面构图；它们不是一套已标定的物理相机内参。

窗景场景 2 的历史效果图测量归一化后，墙地交界为 `0.7375H`；在唯一 `1179×2556 px` 画布上对应约 `y=1885 px`。这是内容构图测量，不是另一个输出画布尺寸。消失点仍按 `(0.50W, 0.58H)` 统一目标检查。墙地交界和透视消失点是两个位置，不可合并。

## 部件生成与验收

| 部件 | 目标 | 检查方法 |
|---|---|---|
| 地面 | 单点透视，横向接缝水平，纵向接缝向上述消失区域收拢 | 延长至少左右各两条纵向接缝；不以墙地交界代替地平线 |
| 供桌台面 | 主题1校准基线：平整桌面前沿长约 `329.8 CSS px`、可见纵深目标 `31.4 CSS px`；后缘/前缘约 `0.856`，纵深/前缘约 `0.0952` | 基准画布 `393×852`、默认桌位；只量平整承载面，排除卷沿、桌沿厚度、围板和桌脚。主题4本次重生成沿用此桌面比例 |
| 席垫 | 当前长条造型下，后缘宽/前缘宽约 `0.72`；纵深投影/前缘宽约 `0.19` | 量席面四角；排除透明留白和前沿厚度 |
| 蒲团 | 圆形顶面呈扁椭圆，短轴/长轴目标 `0.26`，可接受 `0.23–0.29` | 只量顶面的同一圈圆形边界；排除侧壁厚度、流苏及投影 |

主题1桌面基线由用户指定修订：原实测约 `329.8×28.6 CSS px`，纵深目标增加到 `31.4 CSS px`；长度校准容差 `±2 CSS px`、纵深 `±1 CSS px`。旧桌面纵深比 `0.07±0.02` 保留为历史记录，不再限制该校准版。席垫的两个比例仍分别可用 `±0.03` 和 `±0.02` 作初筛。改变真实长宽、纵深或高度时，比例需要随造型变化；**整体消失区域一致优先**，不要为凑比例扭曲器物。蒲团顶面轴比约 `sin(15°)=0.259`，仅作为圆形平面在弱透视下的扁度参考，不能用整体轮廓高宽比反推机位。

既有蒲团的人工候选顶面轴比约为 `0.27`，席垫后前宽比约为 `0.72–0.73`，可以保留这种浅俯观感。当前地面的接缝拟合消失点约在 `0.62H / 0.65H`，与上述统一目标仍有差异；现有素材不能作为所有部件已经共用同一机位的证明。以上为静态分析与人工候选轮廓，未经过用户的视觉确认。

## 通用生成提示词

> 与 Memery 统一镜头匹配：正面居中，轻俯视约 15°，无左右偏转、无滚转、无广角畸变。唯一输出画布为 1179×2556 px（393×852 CSS），透视消失点位于整体画面的 (50%宽，58%高)，默认墙地交界位于 73.2%高，二者不要混淆。地面、供桌台面和席垫的纵深方向统一朝该消失区域收拢。圆形蒲团顶面应是短长轴比约 0.26 的浅扁椭圆，厚度另画，不能用厚度冒充顶面纵深。独立席垫和蒲团使用透明背景，不带地面和投影，直接匹配这台镜头，不再二次做透视变形。

单独生成部件时，同时提供所属主题的整体构图参考；“50%、58%”指整体画布，不能机械套到独立部件 PNG 的画幅上。生成后将供桌、席垫、蒲团放在同一整体构图中审核，确认没有蒲团翘起、席垫陡斜、桌面与地面朝不同方向延伸的观感，再扩展材质候选。
