# 主题 01 设备构图与源图尺寸规范

状态：主题 01 首版已按此规范实现，待用户在 iPhone 16 与 iPad 竖屏截图审计。本文只定义这两种设备的墙纸、框架构图和源图画幅；其他组件暂不扩展。

## 统一规则

- 设计基准为正面竖屏镜头，墙地交界固定在画布高度 `72%`。墙纸与框架只负责墙区，从画布顶端到墙地交界；Pixi 在运行时按当前视口重新计算交界并裁掉越界部分。
- 墙纸铺满墙区的整个宽度和高度，不留白边、不露底色、不拉伸。设备比例有差异时按设备专属构图重绘，不用手机图缩小居中、拉宽或用空墙补两边。
- 框架也是设备专属构图，不能把手机框架横向拉宽。iPad 版应把新增横向面积设计进框架的两侧立柱、衬纸和边饰，使内容区保持宽敞，同时左右连续铺满。木构抵到画幅四边；只有洞门开口透明，格栅两侧由不透明纸面/实体衬底挡住。
- 框架 PNG 画布与同设备墙纸画布同尺寸。顶梁、两侧木构和下沿均抵到画布边缘，不留透明外框或白边；不能依赖视口底色补空。透明通道只留在洞门开口和木构的抗锯齿边缘。
- 其他长宽比设备沿用最近的设备构图：等比缩放并在安全区内裁切，不能非等比拉伸；主体锚点仍以归一化画布坐标布局。iPhone 16 与 iPad 竖屏是首要审核尺寸。

## iPhone 16 竖屏

| 项目 | 规范 |
| --- | --- |
| 参考画布 | `1179 × 2556 px`（CSS `393 × 852`，3×） |
| 墙地交界 | `y = 0.72H = 1840 px`（取整） |
| 墙纸原图 | `1179 × 1840 px`，不透明 PNG |
| 框架原图 | `1179 × 1840 px`，透明 PNG；洞门是透明区域，框架两侧有连续衬底 |
| 填充 | 画布左右铺满，顶边对齐画布顶端，底边对齐墙地交界；框架木构抵到四边，不留白边、不缩窄主体、不拉伸 |
| 构图重点 | 维持当前手机版的洞门比例、开口宽度和正视机位；墙纸在开口内完整承载远景，木框不得挤压遗像与文字区 |

## iPad 竖屏

| 项目 | 规范 |
| --- | --- |
| 参考画布 | `2048 × 2732 px`（3:4 竖屏参考；逻辑画布 `1024 × 1366`） |
| 墙地交界 | `y = 0.72H = 1967 px`（取整） |
| 墙纸原图 | `2048 × 1967 px`，不透明 PNG |
| 框架原图 | `2048 × 1967 px`，透明 PNG；洞门是透明区域，框架两侧有连续衬底 |
| 填充 | 墙区横向和纵向铺满，顶边对齐画布顶端，底边对齐墙地交界；框架木构抵到四边，左右不得出现空白墙带或纯色边栏 |
| 构图重点 | 重新安排横向空间，增加有内容的墙面和框架侧翼；洞门展示区、遗像和题字保持充足宽度。框架保持原木比例，不横向拉宽、不把手机版缩成中间窄海报 |

## 视口适配与导出

1. 以上 PNG 尺寸是 iPhone 16 和 3:4 iPad 审核基准上的**实际导出像素**。iPhone 墙纸/框架为 3× CSS 尺寸；iPad 墙纸/框架为 2×逻辑尺寸，适合高分屏 Pixi 纹理。
2. 基准机型使用 1:1 等比缩放，墙纸与框架四边直接贴合墙区。其他接近该基准的设备才允许等比 cover，裁切不超过画幅宽/高的 2%；洞门中心、遗像安全区、标题安全区不可进入裁切区。禁止非等比拉伸和空白边补齐。
3. 本规范尺寸按设备画布的 72% 墙区高度计算。若实际产品墙地交界改变，两个文件高度必须跟随新交界重新计算，不能保留旧尺寸后靠压缩或空白填充。
4. 墙纸与框架都按同一设备的相同画布和交界导出，并在注册表中分别指定 `phone`、`tablet` 资源。任何一个部件缺少对应设备的专属构图时，不允许静默回退到另一设备的图片。每个新墙纸和框架都必须直接按对应基准长宽比构图，不能先画错画幅再靠缩放填边。
5. 审核截图至少包含 iPhone 16 `393 × 852 CSS px` 与 iPad 3:4 `1024 × 1366 CSS px`，检查四边填充、洞门开口、遗像/文字安全区、墙地裁切线和框架横向比例。

## 当前实现差距

墙纸和月洞门框架已按 iPhone/iPad 基准画幅重绘并接入专用资源。框架的木构抵到画幅边缘，洞门保持透明；墙纸铺满墙区。供桌和地面装饰仍沿用主体设计画布，避免 iPad 横向空间使主体过度放大。
