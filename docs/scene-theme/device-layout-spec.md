# 主题手机竖屏构图与源图尺寸规范

状态：场景美术与资产审核只以 iPhone 16 竖屏为基准。基准画布为 `1179 × 2556 px`（CSS `393 × 852`）。不另做其他设备比例的专属构图或源图。

窗景类场景遵循[窗景墙地光一体化素材规范](window-scene-assets.md)，不把独立墙纸、框架和地坪方案套用到窗景一体层。场景 2 按图二红线映射至图一 `853×1844 px` 源画布的实测值分界：墙 `1360 px / 73.75%`，地 `484 px / 26.25%`；模块化墙体主题沿用 `72% / 28%` 的通用墙地区域。

## 手机构图规则

- 镜头正面居中，垂直线保持垂直，不使用滚转或夸张广角。
- 模块化主题的墙地交界在 `y = 0.72H`。窗景一体层按专属规范及确认过的构图设置交界。
- 墙纸和框架铺满墙面区域，不留白边、透明外带或纯色补边。运行时适配其它视口时只允许等比缩放和安全区裁切，不制作新的设备专属构图，也不做非等比拉伸。
- 拱窗最高点上方保留约 `20–30 CSS px` 的真实墙面。按 `393 CSS px` 的画布宽度折算，约为墙区宽度的 `5%–8%`。墙面连续铺满，不能以透明边代替，也不要扩张成大块墙头。
- 模块化主题的完整框架保持为一张 RGBA PNG；只让设计指定的窗洞透明。窗景一体层则遵循其专属图层与透明区域规范。
- 墙纸、框后花枝、框架与地坪的整体效果按同一手机构图审核；不可用横图裁切或留空补齐来代替合适的源图构图。

## 视口适配与审核

1. iPhone 16 基准机型按 1:1 逻辑尺寸放置墙纸和框架，确保四边贴合墙区。
2. 其它视口沿用已审核的手机构图，等比 `cover` 并只裁切溢出边缘；洞门中心、遗像与标题安全区不能进入裁切范围。
3. 若墙地交界比例发生变化，模块化墙纸和框架源图须按新的墙区高度重导出，不能用压缩或空白区域填补。
4. 用户审核以 iPhone 16 `393 × 852 CSS px` 场景为准，检查边缘填充、窗洞开口、遗像/文字安全区、墙地交界和框架比例。

## 当前资产约定

主题墙纸和模块化框架采用 iPhone 16 墙区源图尺寸。窗景一体层按[窗景墙地光一体化素材规范](window-scene-assets.md)独立检查；席垫、蒲团、供桌和前景沿用同一套手机主体坐标与透视基准。
