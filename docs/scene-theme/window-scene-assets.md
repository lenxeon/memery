# 窗景场景：墙地光一体化与窗外素材拆分

本规范记录场景 2 的确认方向，并供后续采用拱窗/窗景构图的场景沿用。它定义的是美术素材和构图；既有主题的运行时字段仍按各自 manifest 契约维护。

## 固定图层

窗景类场景按下列顺序由底至顶叠放，所有图层使用同一完整画布和原点：

1. **窗外景物画布**：单独一张不透明全幅 PNG，只画窗外山水/远景，不画花枝、室内墙、窗框、地面或光影。
2. **窗外装饰花枝**：单独的透明 RGBA PNG，位于山水之上、室内层之下；不烘焙窗框、墙面或地面。
3. **室内墙地光一体层**：一张完整画布，合成墙面、完整木窗框、地面和同一方向的日照及投影。每个窗格开口使用真实透明 alpha，露出下面的山水和花枝；其它区域不透明。不能把这一层再切成墙纸和单独地坪。

光照与木框属于室内整体关系：窗外自然光让木棂迎光面明亮、清楚地呈现浅木纹，并在地面形成与窗格对应的细线投影。光从窗外进入，不在侧墙另加侧向光带。窗外景物和花枝需要替换时分别替换前两层，不影响墙、窗、地和室内光影构图。

## 场景 2 的测量锚点

以用户提供的 `853 × 1844` 效果图为准：

| 项目 | 固定目标 |
|---|---|
| 画布 | `853 × 1844 px`；三层必须同尺寸、同原点叠放 |
| 墙地交界 | `y = 1360 px`（自顶边起）；墙区行 `0–1359`，高 `1360 px`（`73.75%`）；地面行 `1360–1843`，高 `484 px`（`26.25%`），即 `y ≈ 0.7375H` |
| 窗拱顶 | 约 `y = 0.03H`；顶部保留约 `20–30 CSS px` 的真实墙面 |
| 窗台 | 约 `y = 0.68H`，下方保留参考图中的矮墙与踢脚过渡 |
| 相机与地面 | 正面居中，浅俯视约 `15°`；地面纵向接缝朝统一中心透视区收拢，横向接缝保持水平 |
| 木窗棂 | 细、明亮的浅木质；迎光面亮，侧面只保留窄而柔和的阴影；不做金属质感或粗重叠线 |
| 地板与投影 | 细密清楚的浅木纹；木板接缝与窗格投影线细而明确，避免粗宽暗影、强烈结疤和大块旋涡木纹 |
| 色彩与光源 | 中性日光、克制暖黄；主光来自窗外，不额外照亮侧墙 |

画面尺寸或设备比例改变时，保持归一化锚点一致；不得为了适配而非等比拉伸。三层叠放后须复核窗洞透景、墙地占比、地面透视和投影方向。

测量依据：以图二红色分割线的中心线为界。图二中图一缩略图实际显示宽 `464 px`，其底边界在截图坐标 `y=808`；红线中心位于截图像素行 `y=544`（像素中心坐标 `544.5`）。按图一源宽 `853 px` 映射，墙地边界为 `1844 − (808 − 544.5) × 853 / 464 = 1359.6 px`，取最近整数 `y=1360 px`。墙高与地高分别按画布像素行数计算，边界行 `1360` 计入地面。

## 导出检查

- 三张素材的画布宽高必须完全相同；层序为山水、花枝、室内墙地光。
- 山水底图不透明；花枝图有真实透明背景；室内图除窗洞及其抗锯齿边缘外不透明。
- 每个窗洞中心保持全透明，不能残留山水、花枝、雾气或色点；窗框必须是一张完整图，不拆拱顶和窗棂。
- 室内层的地面与墙面比例、浅俯透视、木纹细节和窗格阴影都在同一相机下完成；不单独替换地板后再补光。
- 不以单独墙纸加独立地坪的组合替代本方案。
