# 场景 2 分层素材

全部 PNG 为 `853 × 1844 px`，同画布、同原点，可直接叠放。

## 图层顺序（底到顶）

1. `outside-landscape.png` — 窗外山水全幅底景；不含花枝与室内构件。
2. `outside-branches.png` — 窗外花枝透明 RGBA 层。
3. `room-wall-ground-light-window.png` — 墙、木窗框、地面与日照/投影合成的一体室内层。只有窗格开口透明，下面的山水与花枝从开口显现。

## 对齐指标

- 参考画布：`853 × 1844 px`。
- 墙地线：图二红线映射至图一源画布后为 `y=1360 px`；墙 `1360 px / 73.75%`，地 `484 px / 26.25%`。
- 相机：正面居中、约 `15°` 浅俯视；地板接缝趋向 `(0.50W, 0.58H)`，横向接缝保持水平。
- 窗棂使用细而明亮的浅木色；地板木纹细腻，窗格投影线目标约 `4–6 px`。
- 光源来自窗外；侧墙不加侧向光带。墙、地和光影保持在同一室内图层，不拆分墙纸与地坪。

窗格透明区已经抽样核对；组合时将山水置底、花枝居中、室内层置顶。
