# 历史实现参考档案库 (Legacy Reference Backup)

本目录为 Memery 线上祈福祭祀台早期 React DOM / SVG 与旧版游戏状态机实现的**1:1 参考档案**。
**本目录不参与任何前端构建与编译**。

---

## 目录索引与查阅指南

### 1. `dom_offerings/`（旧版高保真矢量供品组件）
当在 Pixi 仿真端需要核对、对齐或复刻某种供品的原始造型参数、矢量曲线或渐变色值时，查阅此处：
* **`candle/CandleFlame.tsx`**：原本水滴烛火的贝塞尔水滴形态、内焰金心、烛芯与多层火焰渐变色标。
* **`candle/CandleItem.tsx`**：原本象牙白蜡烛身形、蜡泪凝固痕迹与蜡油凹槽比例。
* **`censer/IncenseSmoke.tsx`**：原本香气袅袅三缕烟的物理漂移、透明度缓动与上升曲线。
* **`censer/CenserItem.tsx`**：原本素雅青瓷香炉的釉色渐变、炉耳造型与香灰插香布局。
* **`flowers/`**：
  * `items/`：15 款传统名花（牡丹、百合、荷花、菊花、康乃馨、郁金香、兰花、水仙等）的花瓣、花蕊、绿叶原始 SVG 几何。
  * `vases/`：12 款雅瓷花器的形制、釉色高光倒角（泥捏翻边陶、珠光涡轮、双色旋拧等）。
* **`fruits/`**：19 款果盘（苹果、柑橘、仙桃、石榴、金桔等）的盘身光泽与多层叠放参数。
* **`tablecloth/`**：6 款宫廷织锦桌布的经纬纱线、回纹边饰与万字垂幔流苏。
* **`singing_bowl/`**：紫铜老钵与实木击锤、回音波纹。
* **`tea_cups/`**：三盏描金白瓷敬茶与红木茶托。

### 2. `game/`（旧版游戏状态与工厂实现）
* **`factories/AbstractItemFactory.ts`**：原本各摆件在供案上的标准初始相对坐标（如左花瓶 `{-164, -4}`、右花瓶 `{164, -4}`、香炉 `{0, 6}`、果盘 `{-118, 16}` 等）。
* **`entities/`**：原本每个供品的数据字段结构（生命值、点燃状态、敲击交互处理）。
* **`lifecycle/useWorldLoop.ts`**：原本基于 React 的世界心跳循环。

### 3. `dom_scene/`（旧版供台场景容器）
* **`AltarTable.tsx`**：原本 770 行 React DOM 案台插槽网格、木纹底座与桌面拖拽定位的原始实现。
